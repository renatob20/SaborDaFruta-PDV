# 📋 Histórico de Versões - Sabor da Fruta PDV

## [1.0.0] - 2025-12-17

### ✨ Primeira Versão Oficial

#### Funcionalidades Principais:
- ✅ **Sistema de Vendas**
  - Venda por quantidade e peso
  - Cálculo automático de troco
  - Carrinho estilo cupom fiscal

- ✅ **Gestão de Produtos**
  - Cadastro completo
  - Controle de estoque
  - Preços por tipo

- ✅ **Impressão de Cupom**
  - Impressora térmica (ESC/POS)
  - Cupom digital com QR Code
  - Servidor HTTP local para celular

- ✅ **Controle de Acesso**
  - Login com usuário e senha
  - Perfis: Admin e Operador
  - Senhas criptografadas (bcrypt)

- ✅ **Banco de Dados**
  - SQLite portátil
  - Migrations automáticas
  - Preserva dados em atualizações

#### Tecnologias:
- Python 3.12
- ttkbootstrap (interface)
- SQLite3 (banco de dados)
- bcrypt (segurança)
- qrcode (cupom digital)
